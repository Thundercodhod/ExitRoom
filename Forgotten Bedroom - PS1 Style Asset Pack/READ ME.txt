* .blend files containing the original Blender source files
* Asset examples and supporting files where included

Extracting the Pack:

The main download includes a file called:

Pack UE5 Assets.zip

Before using the assets, you will need to unzip/extract this file.

Windows:

1. Locate Pack UE5 Assets.zip after downloading it.
2. Right-click the file.
3. Select Extract All...
4. Choose where you would like to extract the pack.
5. Click Extract.
6. Wait for the extraction to finish.
7. Open the extracted folder to access the assets.

After extracting, you can move the folder anywhere on your computer. Avoid moving individual files out of their folders, as keeping the pack structure organised will make importing easier.

Importing Into Unreal Engine 5

To use these assets in an Unreal Engine 5 project:

1. Open your Unreal Engine 5 project (or create a new one).
2. Open the Content Browser.
3. Create a new folder for the asset pack (for example: Retro_Bedroom_Assets).
4. Open the extracted asset pack folder on your computer.
5. Select the files you want to import (recommended is all of them)
6. Drag and drop the files into the Unreal Engine Content Browser or via file explorer into your project.
7. Unreal Engine may open the Import Options window.
8. Adjust the import settings if needed (if any).
9. Click Import (If pops up).

Your models will now appear inside your Unreal Engine project.

Using the Blender Files

The .blend files are included if you would like to modify, customise, or export the assets yourself.

To open them:

1. Install Blender from:
   https://www.blender.org/
2. Open Blender.
3. Select File > Open.
4. Choose the .blend file you would like to edit.

You can then make changes, create new versions, or export the models into other formats.

Notes

* These assets are made with a low-poly PS1-inspired style in mind.
* Materials, lighting, and post-processing effects in Unreal Engine can change the final appearance of the models.
* Some setup may be required depending on your Unreal Engine project settings.
* Always keep backups of your project before importing large asset packs.
