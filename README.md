# ExitRoom — เสียงที่ยืมชื่อเรา

เกม Godot โปรเจกต์เดียว เล่นต่อเนื่อง **หมู่บ้าน / บ้านยาย → Backrooms → ROOM 407 → คำเตือน DON'T FOLLOW THE FROG** ไม่มีสวนล็อบบี้หรือฉากโรงเรียนแล้ว

นนท์กลับบ้านหลังยายเสีย เมย์น้องสาวหายตัวไปเพราะได้ยินเสียงเขาเรียกจากบึง ทั้งที่คืนนั้นเขาอยู่ห้อง 406 ในเมือง เทปยายกับลูกแก้วของเมย์นำเขากลับไปยังความทรงจำที่หายไป และห้อง 407 ที่มีใครอีกคนหน้าตาเหมือนเขา

เนื้อเรื่องฉบับล่าสุดอยู่ใน [STORY.md](STORY.md) เรียงเป็น ROOM 407 → Backrooms → บทกบ พร้อมจังหวะหยุดมองแมงมุมก่อนวิ่งหนี ไฟล์นี้มีเฉพาะตัวเนื้อเรื่อง และยังไม่ถูกนำไปเปลี่ยนลำดับหรือข้อความในตัวเกมที่อธิบายด้านล่าง

## เปิดเล่น

เปิด `project.godot` ที่โฟลเดอร์ ExitRoom ด้วย Godot 4.7 ขึ้นไป รอการ Import แล้วกด F5 หรือเปิด `Play.cmd` เริ่มที่หมู่บ้านตามเดิม

`Room407` เป็นโฟลเดอร์บทหนึ่งในโปรเจกต์หลัก ใช้ `Room407/main.tscn` ไม่ต้องเปิดแอปหรือโปรเจกต์ใหม่ระหว่างเล่น ใช้ `Room407/Play.cmd` เพื่อทดสอบบทนี้โดยตรง ส่วน `PreviewHouse.cmd` ใช้ทดสอบบ้านยาย

1. เดินตามถนนไปบ้านยาย ฟังเทปบนโต๊ะ เก็บลูกแก้วข้างบ้าน แล้วเปิดประตูหลังบ้าน
2. หา EXIT เลข 406 ใน Backrooms ระวังแมงมุมที่ได้ยินเสียงวิ่ง กด E ที่ทางออกเพื่อเข้าสู่ ROOM 407
3. อ่านใบรับห้อง เปิดกล่อง เข้านอน ตรวจประตู 407 กลับนอน ตรวจผนังตอนเช้า แล้วนอนถึงคืนที่สอง
4. เข้าห้อง 407 พบร่างแฝดและอ่านบันทึกจากวันพรุ่งนี้ เพื่อรับคำเตือน DON'T FOLLOW THE FROG

ท้ายบทมีปุ่มสำรวจห้องต่อหรือกลับไปเริ่มเรื่องที่บ้านยาย บทกบยังไม่มีฉากเล่น มีเฉพาะเบาะแสและหน้าส่งต่อเรื่อง ไม่บังคับเข้าไฟล์ฉากที่ยังไม่มี ความคืบหน้าเป็นรายรอบการเล่น ยังไม่มีระบบบันทึกข้ามการปิดเกม

## ควบคุม

- WASD เดิน / เมาส์มอง / Shift วิ่ง / Space กระโดด
- E สำรวจ / F ไฟฉาย / Esc เมนู
- ใน ROOM 407: M ลดการดึงกล้อง / R เริ่มบทใหม่เมื่ออยู่เมนูหรือจบบท

ข้อความจากเทปและลูกแก้วขึ้นแยกจากเป้าหมายประมาณ 18 วินาที กด Esc หยุดเวลาอ่านได้ หน้าบันทึกท้าย ROOM 407 อ่านได้จนกว่าจะกดปุ่ม และเปิดอ่านซ้ำที่เอกสารได้

## ฉากและเครื่องมือ

- `prologue_village.tscn` / `scripts/prologue.gd` — หมู่บ้าน บ้านยาย เทป ลูกแก้ว ประตูหลังบ้าน
- `backrooms_level.tscn` / `scripts/backrooms_level.gd` — เขาวงกตสีเหลือง แมงมุม และทางออก 406
- `Room407/main.tscn` / `Room407/scripts/story.gd` — ห้อง 406/407 เหตุการณ์สองคืน และหน้าส่งต่อบทกบ
- `tools/build_prologue.gd` และ `Room407/tools/build_scene.gd` สร้างฉากใหม่จากโค้ด การรันจะทับการจัดวางด้วยมือ

บ้านยายใช้ `assets/abandoned_house_playable.glb` ดัดแปลงจากโมเดล NeoKG เพื่อให้เดินผ่านประตูได้ ภาพใช้ shader ย้อนยุค 270 พิกเซลแนวตั้ง ส่วน UI ไทยใช้ Noto Sans Thai ดูเครดิตใน `ASSET_CREDITS.md` และ `Room407/ASSET_CREDITS.md`

## ทดสอบ

รันจากโฟลเดอร์ ExitRoom โดยแทน `godot` ด้วยตำแหน่ง executable ในเครื่อง:

```text
godot --headless --path . --import
godot --headless --path . --script res://tests/campaign_flow.gd
godot --headless --path . --script res://Room407/tools/playtest.gd
godot --headless --path . --script res://tests/player_traversal.gd
```

`tests/campaign_flow.gd` ตรวจลำดับเนื้อเรื่องตั้งแต่บ้านยายจนถึงคำเตือนบทกบและเริ่มเรื่องใหม่ ส่วน `tests/capture_campaign.gd` ใช้การเรนเดอร์จริงเพื่อถ่ายหน้าข้อความลง `.buildtmp/`
