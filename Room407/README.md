# ROOM 407 — ห้องที่ไม่มีอยู่

บทที่ 2 ของ ExitRoom ใช้ `../project.godot` เป็นโปรเจกต์หลักเพียงตัวเดียว เปิด `Play.cmd` ในโฟลเดอร์นี้เพื่อทดสอบ ROOM 407 โดยตรง หรือ `../Play.cmd` เพื่อเล่นเนื้อเรื่องต่อเนื่องจากบ้านยาย. แก้ฉาก `Room407/main.tscn` จาก editor ของโปรเจกต์หลัก.

## สถานะ

ฉากต้นแบบที่เล่นได้: ทางเดินชั้น 4 ห้อง 406 และห้องแฝด 407 พร้อมเนื้อเรื่องเข้าพัก คืนแรก เช้าวันถัดมา และคืนที่สอง สิ้นสุดหลังพบร่างตัวเองและบันทึกจากวันพรุ่งนี้ พร้อมเบาะแสส่งต่อไป **DON'T FOLLOW THE FROG**. ตัวเอกคือ **นนท์** จากบ้านยาย ห้อง 407 เป็นความทรงจำก่อนยายเสีย; นี่คือจบตอน ROOM 407 ส่วนบทกบและตอนจบใหญ่ยังไม่ถูกสร้าง.

ใช้เตียง ตู้ โต๊ะข้างเตียง โคมไฟ ประตู และชั้นจาก Forgotten Bedroom; กล่องจาก PomidorkaStudios; texture จริงจาก Soviet Apartment, บ้านร้าง NeoKG และ Poly Haven. ผนัง/พื้น/หน้าต่างประกอบใหม่ให้ทางเดินและเหตุการณ์ทำงานได้ ไม่ได้ใช้ Soviet Apartment ทั้งหลัง.

จอฉากใช้ความละเอียดเสมือน 270 พิกเซลแนวตั้ง พร้อมเบลออ่อน ลดสีและขอบมืด; UI ภาษาไทยยังคมชัด.

## เล่น

- WASD เดิน / Shift เร่งเดิน / Space กระโดด / เมาส์มอง
- E สำรวจหรือเปิดประตู / F ไฟฉาย / Esc เมนู / M ลดการดึงกล้อง
- R เริ่มใหม่เมื่ออยู่เมนูพักหรือจบบททดลอง
- อ่านเอกสารบนตู้ใกล้ประตู 406 → เปิดกล่อง → กด E ที่เตียง → สำรวจประตู 407 → กลับนอน → ตรวจผนังตอนเช้า → กลับนอน → เข้าห้อง 407 → เข้าใกล้เตียง → อ่านเอกสารบนตู้

## ตัวละครและแอนิเมชัน

`assets/models/male_animated.glb` รวมท่าจากไฟล์ FBX ที่ผู้ใช้ส่ง: `idle`, `walk`, `run`, `sit`, `crouch_down`, `stand_up` ซ่อม texture แล้ว แต่ยังไม่ได้ตัด root motion ของท่าเดิน/วิ่ง. ในฉากใช้ `idle` กับร่างที่ปลายทางเดินหลังตรวจประตูคืนแรก; ท่าอื่นเตรียมไว้สำหรับเหตุการณ์ต่อไป.

คนบนเตียงใช้ `male_sleeping.glb` เป็นท่านอนนิ่งชั่วคราว. ยังขาดท่านอนหายใจและลุกจากเตียง. กล้องผู้เล่นเป็นบุคคลที่หนึ่ง ไม่ผูกการเคลื่อนที่กล้องกับแอนิเมชันเดินของร่าง NPC.

## ของที่ยังไม่ใช้ / ข้อจำกัด

- `obj`: ตึกอ้าง texture `Atlas1.png` ซึ่งยังไม่พบ จึงไม่นำตึกที่ไร้ texture มาใช้
- `Urban_Modular_Demo`: พบ 163 glTF ตรวจ URI แล้วไฟล์ที่อ้างอิงครบ เก็บไว้ต่อฉากภายนอก ยังไม่ได้จัดวางหรือทดสอบภาพทุกชิ้น
- `PSX Character.fbx`: ตัวละครอีก rig มีท่าแขนและ T-pose เก็บไว้ก่อน เพราะใช้ Male Character เดียวกันทั้งร่างบนเตียงและแอนิเมชันที่ส่งมา
- `TheWrapper V2`: มี Blender, FBX และ diffuse texture; ยังไม่ได้ใช้หรือยืนยัน rig/animation
- `NEUROZAM-9_PSX_PillBottle`: มี Blender, FBX และ texture; ยังไม่ได้ใช้
- `PSX-Syringe`: มี Blender, FBX และ texture; ยังไม่ได้ใช้
- เสียงลากเป็นเสียงสังเคราะห์ชั่วคราวเพื่อทดสอบจังหวะ ควรแทนด้วยเสียงอัดจริง; ยังไม่มีเสียงพากย์
- แสงเช้าเพิ่ม ambient เพื่อแยกคืน ยังไม่ได้ทำท้องฟ้าหรืออาคารวิวภายนอก

## แก้ไขและตรวจสอบ

ฉากที่ประกอบแล้วเก็บใน `main.tscn` เป็นโหนดแยกตามห้องและเฟอร์นิเจอร์. `tools/build_scene.gd` เป็นตัวสร้างฉาก: รันใหม่จะทับการจัดวางด้วยมือใน main.tscn ให้สำรองก่อนใช้.

`tools/playtest.gd` ตรวจการเดินผ่านประตู การชนกับผนัง 407 ลำดับเหตุการณ์ การคืนควบคุมกล้อง การมีแอนิเมชันครบ และค่าเอฟเฟกต์ภาพ. ตรวจภาพจริงเพิ่มเติมจาก Godot ใน `previews/`.

ลำดับหลัก: บ้านยาย → Backrooms → ROOM 407 → คำเตือนบทกบ ไม่มีสวนหรือโรงเรียน. ทุกคำสั่ง Godot ใช้ `--path` ไปยังโฟลเดอร์ ExitRoom; ตัวอย่างทดสอบ `--headless --path . --script res://Room407/tools/playtest.gd`. เส้นทาง `res://Room407/` อ้างอิงจากโปรเจกต์หลัก.
